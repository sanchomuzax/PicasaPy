# Billentyűparancsok

Csak azok szerepelnek itt, amelyek **tényleg működnek**. A menükben
látható, de szürke tételek billentyűi nem élnek.

## Fájl

| billentyű | mit csinál |
|---|---|
| Ctrl+N | Új album |
| Ctrl+O | Fájl felvétele a Picasába |
| Ctrl+M | Importálás forrása |
| Ctrl+S | Mentés |
| Ctrl+Shift+S | Kép exportálása mappába |
| Ctrl+P | Nyomtatás |
| Ctrl+Shift+P | Indexképek nyomtatása |
| Ctrl+Enter | Keresés a lemezen |
| F2 | Átnevezés |
| Delete | Törlés lemezről a rácsban — albumban és Emberek albumban ehelyett kiveszi a képet az összeállításból |
| Ctrl+Delete | Törlés lemezről (a nézőben) |

## Szerkesztés és kijelölés

| billentyű | mit csinál |
|---|---|
| Ctrl+A | Az összes kijelölése |
| Ctrl+D | Kijelölés törlése |
| Ctrl+I | Kiválasztás megfordítása |
| Ctrl+C | Másolás |
| Ctrl+X | Kivágás |
| Ctrl+R | Forgatás jobbra |
| Ctrl+Shift+R | Forgatás balra |

Egérrel: Ctrl+kattintás egyenkénti hozzávételhez, Shift+kattintás
tartományhoz, húzás a rács üres részéről lasszós kijelöléshez.

## Nézet és panelek

| billentyű | mit csinál |
|---|---|
| Ctrl+1 | Kis indexképek |
| Ctrl+2 | Normál indexképek |
| Ctrl+4 | Diavetítés |
| Ctrl+T | Címkék panel nyitása/zárása |
| Alt+Enter | Tulajdonságok panel |

## A nézőben

| billentyű | mit csinál |
|---|---|
| F | Arcok megjelenítése |
| Shift+F | Arcok szerkesztése |
| Esc | Vissza a könyvtárhoz |

## Diavetítés közben

| billentyű | mit csinál |
|---|---|
| Szóköz | Szünet / folytatás |
| → vagy Enter | Következő kép |
| ← | Előző kép |
| Ctrl+R | Forgatás jobbra |
| Ctrl+Shift+R | Forgatás balra |
| Esc | Kilépés |

## Kollázs-szerkesztés közben

| billentyű | mit csinál |
|---|---|
| Ctrl+A | Az összes kijelölése |
| Ctrl+D | Kijelölés törlése |
| Del | A kijelölt képek eltávolítása a kollázsból |

> A **Súgó ▸ Billentyűkódok** menüpont még nem működik — a billentyűk
> listája ez a lap.
