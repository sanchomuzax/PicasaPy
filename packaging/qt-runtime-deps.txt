# A Qt (PySide6) futtatásához kellő Linux rendszercsomagok — EGYETLEN lista.
#
# Ezt a fájlt olvassa a CI (`.github/workflows/`), a session-indító bootstrap
# (`scripts/bootstrap_env.sh`) és minden más telepítő; tételes `apt-get
# install libegl1 ...` sort SEHOVA nem írunk többé. Őr:
# `tests/test_kornyezet_szinkron.py`.
#
# Előzmény: a lista korábban négy helyen élt párhuzamosan, és el is csúszott —
# a `libpulse0` a CI-be bekerült, a session-hookokba nem, így a felhős
# munkamenet más környezetben futtatta a tesztkészletet, mint amiben a CI
# zöldre váltott.
#
# Lekérdezés:
#   `python scripts/print_dependencies.py --apt`        — csak a KÖTELEZŐK
#   `python scripts/print_dependencies.py --apt-teljes` — a disztribúciósakkal
#
# Formátum: soronként egy csomagnév; `#`-kezdetű és üres sor kimarad.
# A `[csak-disztribucios]` sor alatti tételek CSAK annak kellenek, aki a
# PySide6-ot a disztribúció csomagjából telepíti — a CI-nek NEM (#1491).

# EGL/OpenGL — enélkül a PySide6 be sem töltődik (`libEGL.so.1: cannot open
# shared object file`), még offscreen platformon sem.
libegl1
libgl1

# Billentyűzet-leképezés; a QGuiApplication indulásakor kell.
libxkbcommon0

# Qt Multimedia (videó-lejátszás, #14). Nem minden futás használja, de a
# modul betöltése ezt húzza be — ha hiányzik, a videós rész némán más ágra
# fut, mint a CI-ben.
libpulse0

[csak-disztribucios]

# Qt nyomtatás-támogatás (#1472).
#
# A pip-es PySide6 wheel a QtPrintSupport modult MAGA hozza; ez a tétel CSAK
# annak kell, aki a PySide6-ot a disztribúció csomagjából telepíti (ott a Qt
# modulokra van bontva).
#
# Miért nem a kötelezők között: a CI a KÖTELEZŐ listát futtatja `apt-get
# install`-lal, és ott ez a csomag **eltörte a telepítést** — a lépés
# elhasalt, és vele a `libegl1` sem került fel, tehát MINDEN teszt elbukott
# egy félrevezető `ImportError: libEGL.so.1`-gyel. (Mérve: #1472, a
# 32938928311 futás.) Az őr: `tests/test_fuggoseg_jeloles_1491.py`.
python3-pyside6.qtprintsupport
