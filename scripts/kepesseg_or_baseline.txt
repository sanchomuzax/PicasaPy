# Ez a lista azokat a `@Slot`/`@Property` tagokat rögzíti, amelyek egy
# regisztrált kontextus-objektumon ülnek, de a QML-ből MINŐSÍTETT alakban
# (`<objektum>.<tag>`, aliasokkal együtt) senki nem hivatkozik rájuk. Azért
# van lista, mert az őr bevezetése nem tehette azonnal pirosra a main-t; a
# meglévő tételek javítása külön jegyek dolga.
#
# A LISTA CSAK RÖVIDÜLHET:
#   * ÚJ szakadás → az őr bukik. Kösd be a QML-ből, töröld a tagot, vagy —
#     ha a bekötetlenség TUDATOS — vedd fel ide, indoklással.
#   * A lista HOSSZA sem nőhet: a felső korlát a szkriptben áll
#     (MAX_BASELINE_ENTRIES), ezért új tételhez a számot is emelni kell —
#     azt pedig a felülvizsgálat látja. Ahogy a lista fogy, vidd lejjebb.
#   * Ha egy tétel bekötést kap, a sorát TÖRÖLNI kell: az őr az elavult
#     bejegyzésre is bukik, hogy a lista ne konzerválja a múltat.
#
# Formátum soronként:  <kontextusObjektum>.<tag>  <jegyszám vagy indoklás>
# Indoklás nélküli sor HIBA — a néma engedély pontosan az, ami ide nem kell.
#
# Az indoklások négy fajtája:
#   #NNNN     — van rá nyitott jegy, ott dől el, kap-e felületet
#   BELSŐ     — a terméken belül Pythonból hívjuk; a QML-nek nincs dolga vele
#   FELVÁLTVA — a felület egy MÁSIK, bővebb alakot hív ugyanerre
#   MÉRVE     — a #1476 bevezetésekor mért, még el nem döntött eset
