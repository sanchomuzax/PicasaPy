# YuNet és SFace modellek

`face_detection_yunet_2023mar.onnx` is distributed from the OpenCV Zoo
`face_detection_yunet` model directory and is licensed under the MIT License.
The model is bundled unmodified; its expected size and SHA-256 are recorded in
`picasapy.faces.model_download.DETECTOR_SPEC`.

`face_recognition_sface_2021dec.onnx` is distributed from the OpenCV Zoo
`face_recognition_sface` model directory and is licensed under the Apache-2.0
License. The model is bundled unmodified; its expected size and SHA-256 are
recorded in `picasapy.faces.model_download.EMBEDDER_SPEC`. The downloader uses
the same source only as a fallback when no bundled or user-provided model is
available.
