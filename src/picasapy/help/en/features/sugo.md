# Built-in Help

This help is included with PicasaPy. You can read it without an internet
connection.

## Open Help

Open it in any of these ways:

- Press F1.
- Choose **Help**, then **&Help Contents and Index**.
- Press Shift+F1 to open help for the part of the interface under
  the pointer.

The chapter list and search field are on the left; the selected chapter
appears on the right. Choose **Close** to close the window.

Under **Help**, Keyboard Shortcuts opens the available shortcuts in the
same window, grouped by menu. See [Keyboard Shortcuts](billentyuk.md) for
an explanation. **Check for Updates** is disabled because the Google
service it depended on has been discontinued.

## Move between chapters

- Select a chapter in the list on the left to open it.
- Blue links in the text open the linked chapter. The pointer changes
  to a hand over a link.
- **Back** returns to the previous chapter. It is disabled when there
  is no earlier chapter to return to.
- **Contents** opens the table of contents and clears the search.

Links stay inside Help. If a link points outside Help, PicasaPy does not
navigate away.

## Search

Type in the **Search in help** field at the upper left. Results replace
the chapter list. Each chapter gets one row with its title and a short
excerpt around the match. If a word appears several times in a chapter,
the count appears after the title in parentheses.

Clear the search field to restore the full chapter list.

## Shift+F1

Shift+F1 opens the chapter for the interface area under the pointer:

- over the folder and album list or the photo grid: The Library;
- over the viewer: Viewing photos and videos;
- over the editor panel: The Editor;
- over a collage panel: Collage.

If a dialog is open, Shift+F1 opens its help chapter. For dialogs in
separate windows, including **Print**, **Folder Manager**, **Settings**,
**Import from Source**, and Export as Web Page, Shift+F1 opens the
dialog's chapter and F1 opens the table of contents. Help appears in
front of the dialog; close it to continue working.

If an area has no dedicated chapter, the table of contents opens, just
as it does with F1.

## Copy text

Select chapter text with the mouse, then right-click and choose **Copy**
to put it on the clipboard.
