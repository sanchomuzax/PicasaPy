# PicasaPy Help

This is the PicasaPy user guide. It works offline: every chapter is included
with the application.

PicasaPy is a reimplementation of Google's Picasa photo organizer. If you
know Picasa, much of the layout will feel familiar: the menus, folder list,
Photo Tray, and editor tabs are in familiar places.

The program is still in early development. Some menu items are disabled:
their place is there, but the feature is not ready yet. This guide describes
only what currently works. A separate chapter lists features that are not
available yet.
